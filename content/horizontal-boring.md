# Horizontal boring

Use it for dowel holes and for drilling into the edges and ends of long or wide boards. The table drops **2-3/8"** below the chuck, so you can bore the center of stock up to **4-3/4" thick**. [520 Summary p.8]

## Set up

- [ ] Set the dial to **Slow**, switch off and **unplug**. [520 Summary p.23]
- [ ] Position the headstock. Mount the **drill chuck** fully on the spindle, setscrew on the flat. [520 Summary p.23]
- [ ] Set the table edge **4"** from the chuck, with the table below the chuck. [520 Summary p.23]
- [ ] Chuck the bit and **remove the key**. [520 Summary p.23]
- [ ] Lock check. Leave the quill lock **loose**, because the quill feeds the bit. [520 Summary p.20, p.23]

**Speed:** the same as the drill press. [520 Summary p.29]

| Hole size | Hardwood | Softwood |
|---|---|---|
| Up to 1/4" | H (1600) | I (1750) |
| 1/4"–1/2" | F (1300) | G (1450) |
| 1/2"–3/4" | D (1050) | E (1150) |
| 3/4"–1" | B (850) | C (950) |
| Over 1" | Slow (700) | A (750) |

## First job: bore a hole through

- [ ] Mount the rip fence as a backstop and clamp a scrap board to it. The scrap must stand **taller than the fence**. [520 Summary p.29]
- [ ] Mark the hole on the stock. Fine-tune the hole height with the **table height crank**. [520 Summary p.29]
- [ ] With the machine **off**, extend the quill until the bit's flutes touch the scrap. Set the **depth control 1/8" beyond** that and lock it. [520 Summary p.29]
- [ ] Check the hole position with the machine off. [520 Summary p.29]
- [ ] Switch on, set the speed, and feed with **light, steady pressure**. Back the bit out now and then to clear chips on deep holes. [520 Summary p.29; Horizontal Boring p.3]

**Repeatable depth:** set the depth stop with the flutes just touching the stock. Every hole at that setting comes out the same depth. [520 Summary p.29]

## Common mistakes

- Leaving the key in the chuck. [Horizontal Boring p.2]
- Forcing the bit. [Horizontal Boring p.3]
- Reaching in front of the bit to clear chips. [Horizontal Boring p.2]
- Pressing down unevenly on a row of holes, which puts them at different heights. [520 Summary p.29]
- Doweling: not keeping the marked faces of mating pieces facing the same way. [Horizontal Boring p.7]
