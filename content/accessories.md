# Accessories & hardware

Found something in a box and not sure what it is? Tap **Identify** in the top bar to photograph it, or search the **Parts catalog**.

## How accessories attach

| Where | What goes there |
|---|---|
| **Main spindle** (in the quill) | Saw blade on its arbor, sanding disc, drill chuck, drive center, and drum sanders. Each one pushes fully on and locks with a **setscrew on the spindle flat** (5/32" Allen). [520 Summary p.6, p.20] |
| **Upper auxiliary spindle** | Belt sander, planer, bandsaw, strip sander. [520 Summary p.6] |
| **Lower auxiliary spindle** (runs 1.6× faster) | Jointer, scroll saw. [520 Summary p.6, p.8] |
| **Power mount** (left end) | Extension table and the special-purpose tools. [520 Summary p.6] |
| **Base mount** (right end) | Extension table and the lathe tailstock. [520 Summary p.6] |
| **Carriage** | Worktable, or the lathe tool rest. [520 Summary p.7] |

> Only put an accessory on an auxiliary spindle if it was **designed** for that spindle. [520 Summary p.4]

## Tools that came with the machine

These are the tools used for alignment and mode changes. [520 Summary p.9]

| Tool | Used for |
|---|---|
| 5/32" Allen wrench (long and short) | Accessory setscrews, table insert, miter-slot alignment feeler |
| 5/16" Allen wrench | Trunnion bolts |
| Arbor wrench | Saw blade arbor nut (loosens **clockwise**) [520 Summary p.21] |
| Also handy | 3/16" Allen; 9/16" and 1/2" wrenches; 1/2" socket with extension; an accurate combination square |

## The safety kit

The kit has four pieces. [520 Summary p.3, p.8]
- **Push stick:** for ripping stock 1-1/2"–5" wide.
- **Push block:** for stock over 5" wide.
- **Feather board:** goes **in front of** the blade.
- **Fence straddler:** for stock under 1-1/2" wide.

## Table inserts

The standard insert works for sawing, sanding, drilling and boring. Swap it for the dado, molding, drum-sanding or shaping insert when you need one. When you refit an insert, **tighten the rear screw first**, then draw the front flush. [520 Summary p.7, p.16]
