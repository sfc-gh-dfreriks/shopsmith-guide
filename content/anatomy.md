# Anatomy & controls (Model 520)

Tap **Identify** in the top bar to photograph a part and match it to this list.

## Frame

| Part | What it does |
|---|---|
| Legs | Support the way tubes and bench tubes [520 Summary p.6] |
| Bench tubes | Hold the machine rigid [520 Summary p.6] |
| Way tubes | The two long tubes the headstock and carriage slide on [520 Summary p.6] |
| Base | Pivot that lets the way tubes go horizontal or vertical [520 Summary p.6] |
| Base lock | Holds the machine vertical [520 Summary p.6] |
| Way tube tie bar | Joins the free ends of the way tubes [520 Summary p.6] |
| Headrest and headrest lock | Support the tie bar and hold the machine horizontal [520 Summary p.6] |
| Power mount | Left end. Holds the extension table and the SPTs (bandsaw, jointer, **belt sander**, scroll saw, strip sander, **planer**) [520 Summary p.6] |
| Base mount | Right end. Holds the extension table and lathe tailstock [520 Summary p.6] |
| Accessory mount locks | Clamp whatever is in the power or base mount [520 Summary p.6] |

## Headstock (the power unit)

| Part | What it does |
|---|---|
| Main spindle | Holds blades, discs, chucks and centers [520 Summary p.6] |
| Quill | Sleeve around the main spindle. Extends up to 4-1/4" [520 Summary p.6] |
| Quill feed lever | Extends the quill. Used for drilling and fine fence moves [520 Summary p.6] |
| Quill lock | Locks the quill [520 Summary p.6] |
| Quill feed stop (depth control) | Stops the quill at a set depth [520 Summary p.6] |
| Speed dial | Sets the main and upper auxiliary speed (700–5,200 RPM). **Turn only while running** [520 Summary p.6, p.8] |
| Power switch | On/off with a removable safety key [520 Summary p.6] |
| Headstock lock | Locks the headstock on the way tubes [520 Summary p.6] |
| Auxiliary spindles | **Upper:** bandsaw, belt sander, strip sander, planer. **Lower:** jointer, scroll saw (runs 1.6× faster) [520 Summary p.6, p.8] |
| Logo cover | Access to the wiring and speed changer [520 Summary p.6] |
| Belt cover | Access to the belts and sheaves [520 Summary p.6] |

## Table & carriage

| Part | What it does |
|---|---|
| Worktable and table insert | Work surface. The insert swaps for dado, molding, drum-sanding or shaping inserts [520 Summary p.7] |
| Miter gauge slots | Guide the miter gauge [520 Summary p.7] |
| Miter gauge with safety grip | Holds stock at an angle. Slides or locks in the slot [520 Summary p.7] |
| Rip fence (Pro Fence) | Guide, support or stop. Self-aligns parallel to the blade [520 Summary p.7] |
| Extension table | Extra support in the power or base mount [520 Summary p.7] |
| Table support tubes | Racks that mesh with the carriage pinions [520 Summary p.7] |
| Table height crank and lock | Raise, lower and lock the table [520 Summary p.7] |
| Carriage and carriage lock | Slides on the way tubes and holds the table tubes and tool rest [520 Summary p.7] |
| Trunnions, tilt lock, tilt indicator | Tilt the table 90° left to 45° right, lock it, and show the angle [520 Summary p.7] |
| Table stops | Preset bolts at 90° left, 0° and 45° right [520 Summary p.7] |
| Table tie bar | Supports the table tubes and trunnions [520 Summary p.7] |

## Standard accessories

| Part | What it does |
|---|---|
| 10" saw blade on a 1-1/4" arbor | Ripping and crosscutting [520 Summary p.7] |
| Upper saw guard with riving knife | Covers the blade above the table and resists kickback [520 Summary p.7] |
| Lower saw guard | Covers the blade below the table and has a dust chute. Also used with the sanding disc [520 Summary p.7] |
| 12" sanding disc | Disc sander mode [520 Summary p.7–8] |
| Drill chuck and key | Drill press and horizontal boring modes [520 Summary p.7] |

## Key specs

- **Motor:** 1-1/8 hp. [520 Summary p.8]
- **Saw depth:** 3-1/4" at 0°, 2-3/8" at 45°. [520 Summary p.8]
- **Lathe:** 16-1/2" swing, 34" between centers. [520 Summary p.8]
- **Drill press:** 5/64"–1/2" shanks, 8-1/4" throat, 22" maximum from bit to table. [520 Summary p.8]
